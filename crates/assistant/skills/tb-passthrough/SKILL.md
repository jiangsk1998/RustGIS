# 监测图斑判读·原样透传成果（v2 全量）

取舍口径：只做"一斑单地类"——继承原始图斑范围线、原样透传、不做二次分割；
"一斑多地类"只标疑似并列可能地类，分割留待后续迭代。**任何步骤不得改动几何。**
目标：成果层内全部图斑判定完成（未判读=0），可分多次会话续跑。

## 数据与挂接
- 成果层"成果_透传"：监测图斑面（几何=原始边界）。字段：JCBH 监测编号；
  线索 B/ST/LJ/NC/NM/BGHDL/SFBG/LJBZ/QSX（只作假设不作结论）；
  判定五字段：判定地类代码、判定地类名称、判定依据、拍摄时间、备注（均 text）。
- 挂接链：成果层.JCBH = DKJBXX.DKBH → DKJBXX.BSM = FJ.DKBSM。
- FJ：FJMC 照片名（去重键）、FJ 照片(Image)、PSSJ 拍摄时间、PSJD 方位角(0–359)。
  FJ 无 fid，read_image 用 read_features 返回的 _fid。

## 全量推进（队列式，断点续跑）
1. 取本批清单：read_features(成果_透传, where "判定地类代码 IS NULL",
   order_by JCBH, limit 12) —— 未判读斑按编号升序即下一批。
2. 批量配平：按 COUNT_FJMC 估算，每批实看照片 ≤120 张，超则减斑分批。
3. 每批一个 delegate 子代理，任务自带完整数据约定+步骤+报告格式；**顺序执行**
   （同时只跑一批，避免并发写同一层）。
4. 批间自检通过后再开下一批；中途停止后重跑第 1 步即自动续。
5. 收官验收：summaryStatistics 数 判定地类代码 非空 = 图斑总数；统计单/多比例。

## 判读规范
1. 先 load_skill("photo-interpretation")，按其地类知识库逐条对照。硬约束：
   院内裸土不判1201；斑外棚舍不判1202；耕作层实质破坏不判耕地；无田埂围合水坑不判水田。
2. 记载线索可被照片推翻；跨多拍摄日以最新现状为准，备注记过渡过程。
3. 去重后仍 >12 张的斑，按拍摄日期+方位角均匀抽看 12 张，备注"抽看12/共M张"。
4. 单地类：代码=单码；名称=对应名；依据引照片名(FJMC 前8位…jpg)+所见+知识库要点，
   注明"一斑一地类"，≤150字；备注"无"或疑点。
5. 多地类：代码='主码/次码'（按面积主次）；名称='疑似一斑多地类'；
   备注逐地类列证据与疑点。
6. 与旧成果口径冲突：保留本次判定，备注"与旧成果(旧码)不一致，待复核"。
7. 拍摄时间：PSSJ 去重；单值直写，多值写"最早 ~ 最晚"。

## 写回与自检
1. 写前 run_command("select.clear")。
2. 五字段逐一 edit.calculateField：
   CASE WHEN JCBH='…' THEN '…' ELSE <本字段名> END
   （ELSE 引本字段名保其余斑原值；文本禁英文单引号；一次只写一个字段）。
3. 误写清单外斑必须恢复 NULL。
4. 核对：清单内全部写入、批大小相符；抽 1 个清单外未判斑确认五字段为空。

## 上图
- 标注：labels.field = 判定地类代码（多地类标注即列出可能地类）。
- 样式 unique 按表达式：
  CASE WHEN 判定地类代码 LIKE '%/%' THEN '疑似一斑多地类'
       WHEN 判定地类代码 IS NOT NULL THEN '一斑单地类' ELSE '未判读' END
- 每批写完 select.byAttributes 选本批 JCBH → select.zoomTo 复核。

## 批次报告格式
每斑一行"JCBH｜单/多｜代码（名称）｜依据≤25字"；末尾汇总单/多数量与
"与旧成果不一致"清单；不贴依据全文。

## 推广到其他乡镇
换成果层（同字段口径）+ 换 FJ 子集（XZQDM 或空间范围）即可复用本流程；
挂接链与字段口径不变。
